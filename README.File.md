## 🌟 About the Project

**Fundamental Excel Booster** is a hands-on workbook created to help learners understand and practice essential Microsoft Excel functions. It uses sample Student, Sales, and Employee datasets to demonstrate how formulas can solve everyday spreadsheet tasks.

## 📂 Workbook Overview

| Worksheet | Topics |
|---|---|
| 🎓 `Student_Data` | Grades, logical conditions, text functions, bonus marks |
| 🛒 `Sales_Data` | Sales totals, discounts, commission, lookup functions |
| 👩‍💼 `Employee_Data` | Age calculation and days since joining |

## ✨ Excel Concepts Covered

- **Logical functions:** `IF`, `AND`, `OR`, nested `IF`
- **Text functions:** `LEFT`, `FIND`, `UPPER`, `LOWER`
- **Lookup functions:** `VLOOKUP`
- **Date functions:** `DATEDIF`, `TODAY`
- **Calculations:** multiplication, addition, and date subtraction
- **Absolute references:** for example, `$O$2`
- **Text concatenation:** combining salesperson and month values

## 🧩 Worksheet Details

### 🎓 1. Student_Data
Practice with student IDs, names, and subject marks.

- Assign grades using nested `IF`.
- Check conditions using `AND`.
- Extract first names and change text case.
- Identify top performers.
- Add bonus marks using an absolute cell reference.

### 🛒 2. Sales_Data
Explore salesperson, region, product, month, price, and units sold.

- Calculate total sales (`Price × UnitsSold`).
- Apply discounts using `IF`.
- Check discount eligibility using `OR`.
- Calculate commission using an absolute reference.
- Combine salesperson and month into a lookup key.
- Retrieve product prices using `VLOOKUP`.

### 👩‍💼 3. Employee_Data
Learn date-based calculations with employee information.

- Calculate age using `DATEDIF` and `TODAY`.
- Calculate days since joining using date subtraction.

## 🚀 Getting Started

1. Download or clone this project.
2. Open the `.xlsx` workbook in Microsoft Excel or a compatible spreadsheet application.
3. Explore `Student_Data`, `Sales_Data`, and `Employee_Data`.
4. Select formula cells to understand how each calculation works.
5. Experiment with sample values and observe the results.

> 💡 **Tip:** Try changing marks, bonus values, commission rates, or product codes to explore how the formulas respond.

## 🧰 Requirements

- Microsoft Excel (recommended), or
- LibreOffice Calc or another compatible spreadsheet application

*Note: Some formulas or formatting may behave differently across spreadsheet applications.*

## 🎯 Learning Outcomes

By exploring this workbook, you can practice how to:

- Apply logical conditions to spreadsheet data.
- Clean and transform text with Excel functions.
- Perform sales and commission calculations.
- Retrieve matching values with `VLOOKUP`.
- Use absolute references in formulas.
- Calculate age and elapsed days from dates.
